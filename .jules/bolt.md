## 2024-05-20 - Replace List Comprehensions with Generator Expressions inside any/all functions
**Learning:** Using list comprehensions inside `all()` or `any()` functions constructs a complete array in memory before evaluation, preventing the functions from leveraging short-circuit evaluation. This is an anti-pattern that increases memory allocations and CPU cycles unnecessarily.
**Action:** Use generator expressions inside `all()` and `any()` (e.g., replace `all([x < 10 for x in range(100)])` with `all(x < 10 for x in range(100))`) to allow short-circuiting, immediately returning `False` or `True` on the first mismatch/match.
